# ระบบคลังจุลินทรีย์และบัญชีสรุป (SPA Warehouse & Accounting Management System)
### ศูนย์ผลิตจุลินทรีย์ โรงพยาบาล ๕๐ พรรษา มหาวชิราลงกรณ

ระบบเว็บแอปพลิเคชันบริหารจัดการคลังสินค้า วัตถุดิบ ธุรกรรมรับเข้า-จ่ายออก และบัญชีการเงิน ออกแบบตามมาตรฐานการจัดการคลังสินค้าและการออกรายงานทางการแพทย์/หน่วยงานรัฐ รองรับทั้งการเชื่อมต่อฐานข้อมูล **Supabase Cloud (PostgreSQL)** แบบเรียลไทม์ และโหมดสำรองข้อมูล **Offline Local Storage**

## 🚀 ขั้นตอนการติดตั้งฐานข้อมูล Supabase อัตโนมัติ

1. ไปที่ [Supabase Dashboard](https://supabase.com/dashboard) และเข้าสู่โปรเจกต์ของคุณ (หรือสร้าง Project ใหม่)
2. เมนูด้านซ้ายเลือก **SQL Editor**
3. คลิก **New query**
4. เปิดไฟล์ `supabase_schema.sql` คัดลอกโค้ด SQL ทั้งหมดไปวางในช่อง SQL Editor
5. กดปุ่ม **Run** เพื่อสร้างตาราง 8 ตารางหลัก, Index, RLS Policies และข้อมูลเริ่มต้น (Seed Data)
6. เมื่อรันสำเร็จ ระบบฐานข้อมูล Supabase จะพร้อมใช้งานทันที 100%

### ตารางที่ถูกสร้างขึ้นใน Supabase:
1. `app_users` - ข้อมูลและสิทธิ์ผู้ใช้งาน (Admin / User / Viewer)
2. `products` - ข้อมูลสินค้าหลัก (Master Products)
3. `customers` - รายชื่อหน่วยงาน / ลูกค้า
4. `categories` - หมวดหมู่รายการ
5. `master_items` - แยกรายการบัญชี
6. `stock` - คลังสินค้าปัจจุบันและการเตือนสต๊อก
7. `transactions` - ประวัติธุรกรรมรับเข้า-จ่ายออก
8. `financials` - บันทึกบัญชีรายรับ-รายจ่าย

1. เข้าสู่ระบบ และคลิกที่ปุ่มสถานะฐานข้อมูล **Supabase Cloud** (ด้านบนขวา หรือในแถบด้านซ้าย)

3. ป้อน **Project URL** และ **Anon Public Key** ของท่าน
4. กดปุ่ม **"บันทึกการตั้งค่า & เชื่อมต่อใหม่"**

## 📊 ฟังก์ชันเด่นของระบบ

- **Dual-Mode Engine**: ทำงานแบบ Hybrid สามารถสลับระหว่าง Supabase Cloud และ Local Storage เมื่ออินเทอร์เน็ตไม่เสถียร
- **Real-Time Stock Cart System**: ทำรายการเบิกจ่ายแบบตะกร้าสินค้า ตรวจสอบสต๊อกแบบเรียลไทม์ ป้องกันการเบิกจ่ายเกินสต๊อก
- **Weighted Average Cost (WAC)**: คำนวณต้นทุนเฉลี่ยของสต๊อกอัตโนมัติเมื่อมีการรับเข้าสินค้า
- **Interactive Dashboard & Charts**: แดชบอร์ดสรุป 6 ตัวชี้วัดสำคัญ พร้อมกราฟวิเคราะห์ 4 รูปแบบจาก Chart.js
- **Official Medical & Govt Reports**: ออกรายงานสรุปตามแบบฟอร์มราชการ (ใช้ฟอนต์ **สารบรรณ - Sarabun**) มีจุดลงนามผู้จัดทำและผู้อนุมัติ พร้อมดาวน์โหลดเป็น **PDF** และ **Excel (.xlsx)** ได้ทันที
- **CSV/JSON Bulk Importer**: ระบบนำเข้าข้อมูลแบบกลุ่มผ่านไฟล์ CSV พร้อมตัวจับคู่คอลัมน์อัตโนมัติ
